# Глоссарий

Термины используются в ADR и в плане в этих значениях. Расхождение с бытовым
употреблением намеренное.

**Класс A** — действие, затрагивающее очередь ввода сессии: `SendInput`,
`SetCursorPos`, глобальные хоткеи. Монопольно владеет курсором, поэтому
конфликтует с человеком по построению. См. ADR-0002.

**Класс B** — действие через сообщения и UI Automation: паттерны,
`PostMessage`, захват по окну, протоколы браузера и Office. Очередь ввода не
затрагивает, работает по неактивным, перекрытым, свёрнутым окнам и окнам на
другом столе. Параллельно с человеком.

**Паттерн UIA** — контракт, который контрол объявляет наружу: что с ним можно
сделать и какое у него состояние. `InvokePattern`, `ValuePattern`,
`TogglePattern`, `SelectionItemPattern`, `ExpandCollapsePattern`,
`ScrollItemPattern`, `RangeValuePattern`, `WindowPattern`, `TransformPattern`,
`TextPattern`, `GridPattern`, `LegacyIAccessiblePattern`.

**Clickable point** — точка, которую UIA гарантирует кликабельной: не
перекрытой потомком, видимой, в пределах экрана. Не совпадает с центром
прямоугольника, когда родителя перекрывает дочерний элемент.

**RuntimeId** — идентификатор элемента UIA в пределах одного снимка дерева.
Не стабилен между снимками, поэтому резолв стабильного идентификатора обязан
перепроверять, что элемент жив.

**CacheRequest** — запрос свойств и паттернов для всего поддерева одним
межпроцессным вызовом. Противоположность поэлементного обхода, при котором
каждое свойство каждого элемента — отдельный round-trip. Основное средство
борьбы с медлительностью UIA.

**Семантический снимок** — текстовое дерево доступности с ролями, именами,
состояниями, clickable points и стабильными идентификаторами. Первичное
наблюдение агента. См. ADR-0001.

**Стабильный идентификатор** — короткая метка элемента в снимке (`@e17`),
которой агент адресует действие вместо координаты.

**ElementFromPoint** — разрешение координаты в элемент. Основа предкликовой
проверки: сверить, что по координате лежит именно то, что модель намеревалась
нажать.

**Зондирование цели** (`probe_target`) — опрос того, что цель реально отдаёт:
наличие и глубина дерева UIA, поддержка `TextPattern`, тип приложения, открытый
отладочный порт, пригодный способ захвата, пригодный способ ввода, известные
блокеры. Даёт агенту факты для выбора драйвера вместо угадывания.

**Драйвер** — специализированный путь управления конкретным классом приложений:
браузер по CDP/BiDi, терминал по Console API и `TextPattern`, Office по COM,
общий путь через UIA, пиксельный путь с OCR.

**Канал ввода** — единственный курсор и единственная очередь ввода сессии.
Захватывается действиями Класса A. Политика захвата описывается тройкой
`grant` / `hold` / `block`. См. ADR-0003.

**Пресет захвата** — именованная комбинация `grant`, `hold`, `block`:
`interactive`, `batch-fast`, `batch-safe`, `polite`, `locked`.

**Уровень риска** — классификация шага демоном по разрешённому элементу:
«обратимо» либо «необратимо». Вычисляется после резолва цели, а не до, и
никогда не делегируется модели. См. ADR-0004.

**Предполётная проверка** — assertion перед необратимым шагом: прочитать
фактическое состояние цели (например, адресата сообщения) и сверить с
объявленным. Расхождение прерывает пакет.

**Пакет** — последовательность шагов, исполняемая одним вызовом с одним
наблюдением в конце. Право на пакет имеют только шаги обратимого уровня; пакет
прерывается на любом шаге высокого уровня.

**USER_OVERRIDE** — состояние демона, при котором физический ввод человека
прервал автономию. Релевантно только для Класса A: на пути Класса B
конфликтовать не за что.

**Скрытый desktop** — desktop, созданный через `CreateDesktopW`. В отличие от
виртуального стола, отсутствует в панели переключения, поэтому пользователь не
может попасть на него случайно.

**Виртуальный стол** — группировка окон в пределах той же сессии. Не даёт
изоляции ввода. См. ADR-0006.

**Точка потолка** — цель, недостижимая из пользовательского режима в принципе:
античит с блокировкой `SendInput` на уровне ядра, DRM-контент, secure desktop с
UAC-промптом, exclusive-fullscreen DirectX, elevated-окна из не-elevated
демона.
